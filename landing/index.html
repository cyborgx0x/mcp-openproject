Cấu hình

Mỗi server cần URL của instance và một token truy cập, khai báo trong tệp cấu hình MCP của trợ lý. Tạo token trong OpenProject tại My Account › Access tokens; với Docmost, dùng token đăng nhập của tài khoản. Hướng dẫn chi tiết nằm trong README của từng repo.
